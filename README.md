# Breakfast Run

A top-down micro-car racer for the ZX Spectrum 48K, written in Z80 assembler
(pasmo). Personal home project - Grant learning to code the Spectrum.
Inspired by the *genre* of Micro Machines / Super Off Road / Super Sprint:
tiny cars, momentum and drift, household tracks. Original game, original art.

## Stage 2 (this build) - the track scrolls, the car stays in the middle
- Keys: **O** left, **P** right, **Q** accelerate, **A** brake/reverse
- Straight top-down. A 576 x 448 breakfast-table world (72 x 56 tiles of 8x8),
  viewed through a 192 x 128 window; the camera keeps the car in the middle
- Built in a back buffer each picture, then copied to the screen: about 17
  pictures a second (one every 3 TV frames); physics runs every TV frame
- The window is one colour pair - Spectrum colour comes in 8x8 blocks and
  cannot follow a 1-pixel scroll
- Car art is still a PLACEHOLDER generated by `tools/make_data.py`

Stage 1 (one car, one single-screen track) is tag `stage1-verified` / commit 8501179.

## Build
    python3 tools/make_data.py                       # regenerates src/data.asm (car, thrust)
    python3 tools/make_world.py                      # regenerates src/world.asm (track)
    bash <retro plugin>/skills/zxspectrum/scripts/build.sh asm src/racer.asm build/racer.tap racer
    (cd src && pasmo racer.asm ../build/racer.bin ../build/racer.sym)
    python3 tests/drive_test.py                       # real 48K ROM test, 11 checks
    python3 tests/capture_gif.py                      # build/stage2_drive.gif

## Files
- `src/racer.asm` - the game (commented for learning, BASIC equivalents given)
- `src/data.asm` - GENERATED: car sprites, thrust table
- `src/world.asm` - GENERATED: tiles, world map, surface map
- `tools/make_data.py`, `tools/make_world.py` - the generators
- `tests/drive_test.py` - headless test on the genuine 48K ROM (zx package)
