Breakfast Run Sound Lab

Everything here is the Spectrum's one-bit speaker, simulated. Press play, choose one in each group, then copy your picks from the bar at the bottom and paste them back to Claude. Sound starts only when you press a button.

Racing ditties, new

Four faster tunes written for racing, all played the half-miner way you said was okay: 4 thousandths of a second of the note, low in pitch, once a picture. The newest tape plays Green Light.

The earlier eight, half-miner

The same tunes as before, now played the half-miner way.

Half-miner variations

Kettle's On played three other ways. The game already uses the shorter one by itself whenever it is running flat out, so the music costs less speed.

Event sounds

The game is now quiet between events. Each group below is one event; the option marked "in this build" is what the newest tape plays. The others are ready to build if you choose them.

The ditties are recordings made by the game's tools. The event sounds are made in this page from the same speaker timings the game would use, so the real machine will sound close to this, not identical.
